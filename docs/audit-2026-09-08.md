# Portfolio audit, 8 September 2026

This review preserves the published page structure, section order, typography direction, portrait, mouse lighting, reactive backgrounds and analytical models. The changes address specific usability and maintenance issues. They are saved for review and are not published.

## Findings and implemented fixes

1. The mobile work list hid the individual and team labels. Those labels now remain visible beneath each case summary.
2. The case contents list numbered Contribution as 06 even though the article numbered it 07. Next iteration now has its own anchor and contents entry, keeping navigation and article numbering consistent.
3. Search and theme controls overrode the shared text size with smaller values. Controls and search descriptions now use 14px text, with 44px minimum button heights. Search results can stack their case type on narrow screens.
4. The menu did not identify the current page or work section. It now includes an active state with a corresponding accessibility attribute.
5. Contact links shifted horizontally on hover. Their colour and surface response remain, while the text stays aligned.
6. Work filters and model choices had group labels without group semantics. These controls now expose labelled groups.
7. The model fallback described itself as a text view while showing a diagram. Its status and explanation now describe the actual static diagram.
8. Motion preferences were captured only at page load. Turning on reduced motion now stops pointer updates and reveals any pending content immediately. Normal pointer lighting and reveal behaviour remain intact.
9. Profile, research, work and contact links inherited homepage social titles and descriptions. Their metadata now matches the destination. Case study social URLs now match their canonical addresses. Existing social artwork is preserved.
10. The local lint command scanned generated development output. It now excludes that output and checks the source correctly.

## Validation

The repository lint, TypeScript checks and production static export pass. Export inspection covers the 9 public content routes and the generated 404 page. Each has 1 H1, no duplicate IDs and no missing image alt attributes. Internal file and section references resolve. Canonical and social URLs agree.

The public CV is a valid, tagged, unencrypted PDF with 1 page and a size of 85,816 bytes. Its existing download links are preserved. The portrait is 223,104 bytes. No new dependencies, font downloads, image files or third party scripts are introduced by this pass.

The source colours for secondary text, tertiary text and links exceed a 4.5:1 contrast ratio against the plain light and dark background colours. The lowest checked pair is 5.21:1. These calculations do not certify text over every translucent surface or moving light effect.

The models continue to import Three.js near the viewport, cap rendering resolution, suspend animation offscreen and provide static diagrams. Reported research coefficients, sample sizes and model comparison results are unchanged. Individual and team attribution remains explicit. DualMind remains excluded.

## Limits of this audit

The browser preview stopped on both permitted connection attempts. Fresh screenshots, desktop and mobile visual inspection, keyboard interaction, live theme switching, clipboard behaviour, browser downloads, reduced motion switching and WebGL controls could not be verified in this pass. Source and export checks are not a substitute for those tests. No Lighthouse score, real device performance claim or accessibility certification is made. Browser review should happen before publication.

LinkedIn delivery and the launch of a local email application were not tested. Original academic files were not available in this audit, so the published academic claims were preserved rather than independently reverified.
